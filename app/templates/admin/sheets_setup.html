Google Sheets Auto-Sync Setup

How to automatically push dinner sign-ups to missionary devices in 2 minutes.

← Back to Dashboard

Why Google Sheets?

Missionary smartphones and tablets use Church Mobile Device Management (MDM) security profiles (like Maas360 or Samsung Knox), which heavily restrict browsing to general internet websites. However, the Google Sheets app is universally whitelisted and accessible to missionaries.

With Nourish, whenever a ward member signs up for a dinner, changes their time, or leaves dietary notes, Nourish immediately writes the entry into their Google Sheet so the missionaries see their updated calendar instantly on their phones!

Quick Setup via Google Apps Script (Recommended)

You don't need to configure Google Cloud Console, API keys, or service accounts. Just follow these steps:

  1. Create a Google Sheet:

    Go to sheets.new and create a spreadsheet (e.g. "Elders Dinner Calendar"). Share read/edit access with the missionaries' Gmail accounts.

  2. Open Apps Script:

    In your spreadsheet menu bar, click Extensions > Apps Script.

  3. Paste the Code:

    Delete any existing code in the script editor, and paste the code block below:

    {{ script_template }}
  4. Deploy as Web App:

    Click the blue Deploy button (top right) > New deployment.

    • Click the gear icon next to "Select type" and choose Web app.
    • Description: Nourish Calendar Sync
    • Execute as: Me (your account)
    • Who has access: Anyone (required so Nourish can POST updates)
    • Click Deploy and approve permissions if prompted.
  5. Copy the Web App URL into Nourish:

    Copy the generated Web App URL (starts with https://script.google.com/macros/s/.../exec) and paste it into the Google Apps Script Webhook URL field of the companionship in Nourish.
